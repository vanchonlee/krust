# Atlassian Work Management

Use Atlassian MCP tools for Jira, Confluence, Compass, Jira Service Management, and Bitbucket requests. Discover the accessible Atlassian resource or cloud identifier first when a downstream operation requires it; that prerequisite is part of the workflow, not a substitute for the requested action.

Search for the smallest set of tools needed for the current request. Avoid repeating account or resource discovery within the same turn. Prefer read-only lookup before mutations, and confirm the target project, issue, page, repository, or service before changing it.

Never ask the user to paste credentials into chat. OAuth is managed by the enabled plugin.
